# 等级、备注与增量质检（2026-09-16）

人工应用等级 > 自动质检等级 > 采集等级。人工结果独立存储在 runtime/var/grade-selections，按数据集目录和 episode UUID（没有 UUID 时使用目录名）关联。

- 重复质检、全量重检、VLM 结果更新、服务重启均保留人工等级、可选原因备注与问题类型。逐条再次保存才更新该人工结果；批量采用其他等级会跳过逐条人工复核记录。
- 保存等级只验证当前记录与编辑版本，原子保存等级和备注，不读取媒体或执行质检、旧审批。前端更新受影响行和统计；并发编辑冲突要求刷新，不覆盖另一位操作者。
- 默认按钮为“增量质检 HDF5”，不重编号。来源未变、规则与模型/类别设置一致且已完成的报告复用；新增、变化或执行未完成的记录重新检查。日志列出发现、复用与待检查数量。
- “全部重新质检”重算数值，继续复用签名匹配的 VLM 结果。内容、检查证据、模型或规则变化后旧结果不冒充当前结果。升级到第 7 版规则后，旧自动报告需要更新一次；人工结果保留。
- 文件指纹以设备、inode、大小、mtime、ctime 校验后复用 SHA256；发生变化重新读取内容。质检中源数据变化会中止该条，保留错误供重试。
- 升降柱不参与 HDF5 和 LeRobot 质检。提示词允许单双手模板、任意非空商品名、大小写、多余空白和可选末尾句号。
- 网络/模型失败、不可用证据、夹爪次数/时序/反馈、疑似跳变、连续静止、提示词、视觉疑似不匹配为 B 或待人工复核；不会因此自动 F。结构损坏、无法对齐的帧数、维度错误、NaN/Inf、不可解码视频保留硬失败。人工 F 保留。
- 类别识别关闭时不调用 YOLO/图像模型；独立数值动作复核继续运行，错误注明动作复核，不能显示为视觉检查失败。
- 转换与左右手切分默认不质检，无人工审批前置条件。LeRobot 质检为独立可选按钮。再次转换按当前目录全部数据生成，已有同名输出备份后更新；本次不引入 LeRobot 增量追加。

历史自动报告通过展示层应用当前分级规则；原报告不被重写。有足够基础检查证据且仅被废弃/预警项判 F 的旧报告显示 B/待复核，人工已应用的结果优先。

2026-09-16 上线复核补充：旧格式“采用采集等级/采用质检等级”的人工选择先迁移再检查报告版本，避免报告更新丢失选择。自动任务的数值重检、规则升级、离线刷新均保留已保存的人工等级和备注；真正的结构硬失败仍阻止自动派生和导出，自动检查状态与人工等级分开。旧报告中的升降柱、时间戳预警按当前规则解释，人工复核接口也使用同一规则。
