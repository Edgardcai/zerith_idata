# 商超全流程质检

在 9990 首页点击“商超全流程质检”，或访问 `/market/`。进入页面即递归汇总 `robot_station/data` 下所有商超录制目录，数量、等级和目录列表每 5 秒自动刷新。没有预选的质检 / 转换目录，也不沿用浏览器记住的旧路径。选择操作目录后，概览与报告仍显示所有目录；任务只递归处理明确选择的目录，不按模型端口分组。跳过普通推理、`.partial`、符号链接和 `lerobot` 输出；后端拒绝对整个 `data` 根目录启动任务。

页面直接复用本机原质检页的布局、样式、数据概览、质检表格、报告弹窗、编号映射和 HDF5 回放组件。同在 9990，无需另开端口；顶部可返回原页面。

1. 在“选择质检 / 转换目录”中选择一批录制，或输入自定义目录并点击“使用此目录”。下拉列表显示各目录的数量和 A/B/F 等级分布；未选择目录时不会启动任务。点击“增量质检 HDF5”或“一键质检当前目录”都只处理该目录；点击按钮时会重新读取输入框，避免修改路径后未点“使用此目录”而处理旧目录。“全部重新质检”仅控制本批缓存复用，停止按钮保留已完成报告。
2. “质检报告”沿用原来的分页、等级/编号筛选、勾选与等级保存。可一键筛选未人工质检记录，人工等级最高优先，YOLO 单独参考。
3. 点击“回放”或“HDF5 数据可视化回放”，继续使用原来的三路视频、上下条切换、逐帧/倍速、时间轴、23 维 State/Action 曲线及数值表。阶段按钮按实际记录定位导航、抓取、运送、递交、返回等阶段；“各阶段人工质检”独立保存阶段 A/B/F 和备注，原人工栏保存整体评级。
4. “直接转换 LeRobot”和“当前目录质检并转 LeRobot”都会先完成所选目录的增量全流程质检，再按所选等级（默认 A/B）分级转换。任务针对所选目录的全部记录，不受表格搜索或勾选影响。转换完成后，“编号映射”显示来源路径、UUID 与等级内独立编号。LeRobot 可视化入口沿用原页面。

推荐的目录轮换顺序：先结束当前一批的录制并等待收尾，将 `market_recordings` 改名为 `market_recordings2`，再新建空的 `market_recordings` 继续录制；平台选择 `market_recordings2` 进行质检和转换。目标名称已存在时先安排上一批数据，不合并覆盖。转换期间保持 `market_recordings2` 的名称和内容不变，等任务结束后再轮换下一批。

任务锁禁止同时启动第二个质检/转换任务；目录设备号和 inode 在提交时固定，任务中发现该目录被移动、删除或替换则停止，不发布半批数据。每个任务生成唯一输出目录并拒绝覆盖。报告与人工阶段评级按片段 UUID 查找并兼容旧路径记录，因此目录改名后仍保留；新的同名目录使用新 UUID，不沿用上一批的等级和缓存。其他目录的持续录制不加入本批任务。

原页面不适用的按钮保留置灰，包括左右手切分、原始帧裁剪、两阶段边界订正、静止帧剔除、原抓取规则 LeRobot 复检和 HDF5 等级回写。未接入的原页面配置也置灰说明，不会提交到旧的两阶段处理接口。

检查涵盖结构、23 维状态/动作有效位、时间戳、全帧内嵌图像与视频解码、阶段顺序、连续帧覆盖、HDF5/JSON 边界一致性、阶段执行记录、手臂连续性、底盘末速度、抓取闭合与反馈、运送张开指令及递交释放。已有 YOLO 结果作为抓取参考，不重新调用模型，不使用旧的左右手两阶段或全程静止规则。阶段缺失、额外重试和时序异常为待复核；结构/媒体硬失败单独标记。数值通过不证明真实到位、持物、无碰撞或实际交接成功，界面保留对应视频人工复核项。

整体人工等级优先。已存在的 2889 人工等级会被读取；在配置的 2889 录制目录中保存整体评级会同步写回其原接口。额外商超目录未配置到 2889 时，人工评级保存在本模式独立记录。阶段人工结果保留，源文件/阶段变化时旧阶段审批失效；质检复跑不覆盖人工结果。报告和阶段备注位于 `runtime/var/market-qc/`。

每次转换按等级分别生成完整、独立的 LeRobot v2.1 数据集：

```text
/home/robot/workspace/robot_station/data/lerobot/market_all_<任务编号>/
  A/{data,meta,videos}/
  B/{data,meta,videos}/
  F/{data,meta,videos}/  # 仅在勾选 F 且存在可导出记录时生成
```

原始 HDF5 字段随每条转换记录保存在 `meta/source_fields/episode_XXXXXX.zip`，并在编号映射中记录归档路径。归档保留原始路径、数据类型、精度、形状、属性及时间戳，因此底盘 x/y/yaw、关节力矩、相机位姿、时间对齐信息等也可读取。三路彩色相机字段默认映射到 LeRobot 视频；如需归档原始 JPEG 字节，将 `DATAQC_MARKET_SOURCE_CAMERAS` 设置为 `original`。使用 `dataqc.market_source_fields.read_source_field(dataset, index, hdf5_path)` 读取原始值或相机视频路径。

每个等级独立编号 episode、全局帧和任务，并计算该等级自己的统计信息。不按模型端口拆分；同等级内合并。没有记录的等级不生成空数据集。整批在校验通过后一次性发布，失败或取消不会出现半批已发布的等级。

Parquet 保留逐帧 `phase_index`、各阶段提示词的 `task_index` 以及 `action_valid`；未知动作保持原值，不填零伪装有效指令。来源路径、UUID、模型地址、原始时间戳、实际阶段范围和人工/自动等级保存在 `meta/episode_name_mapping.json`。视频必要时转为 H.264。三路视频帧数、数据集字段、任务/阶段覆盖及源版本在发布前核验。

支持三阶段、标准四阶段、带返回的五阶段及额外/重复阶段；严格保留实际阶段顺序、提示词和全部帧。缺失或重试流程仍在质检中提示，但不因阶段数量排除；缺失阶段的提示占位项不写入输出。每条映射的 `phase_names` 和 `stages` 对应该条实际布局，等级报告的 `phase_sequences` 列出该等级的全部布局。

默认排除未完整结束录制、本次质检执行失败、未完成当前质检、结构/媒体硬失败、阶段帧边界无效或不连续、等级不符或不满足人工筛选的记录；原因写入 `selection.json` 和 `market_qc_report.json`。同 UUID 的不同源目录分别转换，来源路径和原 UUID 均保留在映射中；质检报告按源文件签名隔离，避免副本互相覆盖。`selection.json` 记录重复 UUID 组数及保留全部源目录的策略。未完成收尾的 `.partial` 目录单独列入 `not_scanned`，同时记录选择的等级与扫描数量；页面任务信息显示未扫描目录数量。若转换期间数据或人工等级变化，不发布该批输出。失败中间结果保留在 `.partial`，不会混入已发布数据。不会执行旧的左右手切分，也不自动删除静止帧。服务中断的任务显示为中断；再次运行可复用已完成质检。

历史混合导出可以在不读取源 HDF5 的情况下按已保存等级整理：

```bash
.venv/bin/python -m dataqc.market_regroup /已有混合数据集 /新的分级输出目录
```

此操作保留原混合数据集，重新编号并重算各等级统计，保留逐帧状态、动作、有效位、阶段和视频；输出明确标记“沿用原导出评级、未重新质检源录制”。目标已存在时拒绝覆盖。

1.1.0 使用 `market_recorded_phases_v2` 规则；增量质检会重新检查实际阶段，对源文件签名未变的 v1 报告复用原媒体/数值检查证据，并记录其时间。强制重新质检或源文件变化仍执行全量检查。规则升级保持源数据签名不变，保留已有人工阶段评级。
