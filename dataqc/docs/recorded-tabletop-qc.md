# 桌面取放质检适配

`collection_task.json` 声明 `targets.prompt_mode=tabletop` 时，腰头姿态按
`targets.fixed_pose.config` 中记录的目标核对，保持原有 ±0.02 rad 均值/分位数范围。
不从实测数据反推目标，不修改采集文件。缺少固定姿态时保留原检查。

明确声明的左放、右放、左取、右取四阶段，通过 `stage_prompts` 的手别/操作及
HDF5 `subtask_transitions` 建立对应关系。边界必须递增且完整覆盖记录；夹爪反馈延迟、
错误阶段归属和长静止预警仍保留。自由任务文本不参与分级。

原有数值/视频检查缓存可复用，只重算相关姿态及阶段指标。完整的模型结果按修正后的
可追溯指标重新校验；原结果保存在缓存 `motion/recorded-task-history/`。
未完成或签名不匹配的模型结果不冒充已完成。全量模型重跑不是适配的前提。

设置 `motion_detail_review=false` 使用已完整校验的批量模型结论，关闭额外逐条模型解释。
真实预警、逐条证据校验和人工复核标记不取消，模型缺项/无效回答仍按原规则处理。
