# 最终版发布验收

版本：1.0.0。分支：`dataqc`。仓库中的系统目录：`dataqc/`。

## 验证结果

- 完整回归测试：**179 passed**，覆盖真机／仿真 HDF5、等级优先级、批量模型复核、人工保存、静止处理、LeRobot 转换与切分。仅有依赖库的 TestClient 弃用提示。
- 命令：`PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m pytest -q -p no:cacheprovider`。
- 在新的仓库目录启动 Web 服务，验证模块均从新路径加载，LeRobot 0.3.3 读取组件可导入。
- Chromium 真实数据只读验证：主页面、待复核筛选、三视角回放，在 1920×940、1536×740、1366×680 的浏览器可用区域内正常显示；仿真三路视频正常播放，无页面脚本错误。
- 服务模板通过 `systemd-analyze --user verify`。
- 发布文件检查：无实际 API 密钥、运行数据库、模型权重、采集视频、HDF5、日志或虚拟环境；无大于 10 MB 的文件。
- `pyproject.toml` 固定版本与验收机器已安装版本一致。

## 整理内容

移除开发截图、实验日志、一次性升级脚本、旧采集／ROS 工程副本、重复测试与安装器缓存。
将仍需使用的测试数据生成器提取到当前测试目录，保留实际运行的兼容层与第三方许可证。

把当前使用、部署、数据格式、等级冲突规则集中到 `docs/`，提供不含凭据的配置示例与路径可迁移的服务模板。
