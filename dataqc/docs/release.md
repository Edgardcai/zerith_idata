- 质检报告按文件签名分别保存，避免副本覆盖彼此的报告；兼容原 UUID 报告及目录移动。

## 1.1.0 · 2026-11-03

- 商超转换按录制的实际阶段导出，支持三/四/五阶段、返回及额外/重试阶段；不再因固定四阶段规则漏掉已选等级的数据。
- 缺失/重试流程保留质检提示；输出仅包含实际阶段，保留全部帧、逐帧任务、动作有效位和来源映射。独立校验继续拒绝边界空洞、重叠、HDF5/JSON 不一致和损坏媒体。
- 各等级可混合不同阶段布局；阶段名称与人工评级按实际阶段数量处理，界面显示返回阶段。
- 增量升级重算阶段检查，复用签名未变的旧媒体证据；人工评级保留。未收尾 .partial 目录单独列入报告，不再默默漏计。

验证：商超、工作台、部署回归 60 项通过；包含混合阶段导出、LeRobot 返回阶段视频回读、全帧状态/动作对比、旧报告升级与未收尾目录报告。真实目录预检 134 条均通过阶段边界与结构检查（A 123、B 1、F 10）。

## 1.0.1 · 2026-10-22

- 一键质检及质检转换只处理输入框所选目录；默认上一批 `market_recordings2`，目录不存在时不回退，禁止对整个 data 根目录提交任务。
- 支持录制目录轮换：按片段 UUID 保留旧报告和阶段人工评级，同路径新批次不继承旧结果；任务期间检测目录替换并停止，防止串批。
- 商超批量导出按 A/B/F 生成独立的 LeRobot v2.1 数据集，各等级独立编号、任务索引及统计，不再混合。
- 编号映射显示各等级实际数据集路径；仍可读取历史混合输出。
- 导出排除未完整结束录制、本次质检执行失败及无效 UUID；全部排除时仍保留 selection.json。
- 分级输出在整批结构、视频、任务覆盖、源版本及评级一致性校验通过后发布；取消或变化不发布半批结果。
- 增加已有混合导出的分级整理工具，不依赖已删除的源录制，并明确沿用历史评级、没有重新质检。
- 源码以当前部署目录内的 Git 提交和标签记录；环境、vendor 依赖及运行数据保持在 Git 外。

验证：商超、工作台与部署回归 49 项通过；最后补充的目录/映射检查 4 项通过；包含本机 LeRobot 读取器加载、任务文本与视频帧回读。
